# Eugine Jose — Portfolio

Personal software engineering portfolio built with the Next.js App Router. It
highlights application modernization work across mobile, web, and desktop
software, with project case studies, experience, technical skills, and a
downloadable résumé.

## Stack

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

These checks also run in GitHub Actions for pushes and pull requests.

## Analytics

The site uses Vercel Web Analytics for aggregated page-view reporting. It
records page and referrer information along with coarse location and device
details; it does not use third-party cookies. Vercel says its temporary
visitor hash is discarded after 24 hours. Enable Web Analytics in the
project's Vercel dashboard before deployment. See Vercel's
[privacy documentation](https://vercel.com/docs/analytics/privacy-policy).

## Portfolio assets

- Résumé: `public/Eugine_Jose_Resume.pdf`
- Project and profile images: `public/`
- Main page sections: `app/sections/`

The portfolio is deployed at [eugine-jose.vercel.app](https://eugine-jose.vercel.app).
